# DiverMente — Centro de Atención Integral Familiar y Desarrollo Infantil

Proyecto web profesional y responsivo construido con React, Vite y TailwindCSS para el sitio de DiverMente.

## Comandos

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Características

- React + Vite + TypeScript
- TailwindCSS con diseño moderno y minimalista
- Framer Motion para animaciones suaves
- SwiperJS para carruseles
- React Router para navegación escalable
- SEO básico con meta tags y Open Graph
- Responsive mobile/tablet/desktop
- Arquitectura preparada para futuro backend

## Deploy

- Preparado para Vercel
- Preparado para GitHub Pages

## Estructura

- `/src/components`
- `/src/pages`
- `/src/data`
- `/src/styles`
- `/public`
